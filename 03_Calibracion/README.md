# Revalidación del montaje

Verificar alimentaciones, conexiones y masa común; medir en J5 y J9; confirmar polaridad, offset de ADC, pasos DAC positivo/negativo, frecuencia de timer y periodo con Rigol. Registrar tabla de calibración vigente y fecha. NO asumir que los datos históricos son los actuales.

Preparar prueba de DAC=0 y parada inmediata antes de cerrar el lazo.
